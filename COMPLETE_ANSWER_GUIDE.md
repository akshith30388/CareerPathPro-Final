## SECTION 1: APTITUDE (Questions 1-5)
*Measuring logical reasoning, problem-solving, and technical knowledge*

### Q1: Train Speed Calculation
**Question**: If a train travels 120 km in 2 hours, what is its speed?

**Options**:
- A. 60 km/h ✓ **CORRECT**
- B. 50 km/h
- C. 70 km/h
- D. 80 km/h

**Explanation**: Speed = Distance ÷ Time = 120 ÷ 2 = **60 km/h**
**Career Path**: Technical, Analytical roles

---

### Q2: Odd One Out
**Question**: Which is the odd one out: Apple, Mango, Carrot, Banana?

**Options**:
- A. Apple
- B. Mango
- C. Carrot ✓ **CORRECT** (Only vegetable; rest are fruits)
- D. Banana

**Explanation**: Apple, Mango, and Banana are all **fruits**. Carrot is a **vegetable**.
**Career Path**: Analytical, Research-oriented roles

### Q4: HTML Definition
**Question**: What does HTML stand for in web development?

**Options**:
- A. Hyper Text Markup Language ✓ **CORRECT**
- B. High Text Modern Language
- C. Hyperlink Text Making Language
- D. Home Text Markup Layout

**Explanation**: **HTML** (Hyper Text Markup Language) is the standard markup language for creating web pages.
**Career Path**: Web Development, Frontend Development

### Q5: Data Structure
**Question**: Which of the following is a data structure?

**Options**:
- A. Algorithm
- B. Stack ✓ **CORRECT** (Along with Queue, Array, List, Tree, Graph)
- C. Compiler
- D. Browser

**Explanation**: **Stack** is a fundamental data structure (LIFO: Last-In-First-Out). Algorithm, Compiler, and Browser are different concepts.
**Career Path**: Software Engineering, Computer Science
